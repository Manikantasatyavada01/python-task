1. What is a Pandas Series? Write down its key features.¶

A Pandas Series is like a column in a table. It is a one-dimensional array holding data of any type.

Pandas Series is a one-dimensional labeled array capable of holding data of any type (integer, float, string, Python objects, etc.). Here are some key features of a Pandas Series:

  • One-dimensional labeled array: Data stored with an associated index (labels).
  • Indexing: Supports both integer-based and label-based indexing for easy data access.
  • Data types: Can hold heterogeneous data types within the series.
  • Creation flexibility: Can be created from lists, NumPy arrays, dictionaries, or scalar values.
  • Custom indices: You can specify custom index labels; otherwise, a default integer index is applied.
  • Vectorized operations: Supports element-wise arithmetic operations efficiently.
  • Automatic alignment: When performing operations between two Series, Pandas automatically aligns data based on their index labels.
  • Handling missing data: Supports NaN (Not a Number) for missing values with built-in handling.
  • Built-in methods: Offers many methods for manipulation, selection, and statistical operations.
  • Supports time series data: Specialized features for datetime-like data.
  • Integration with NumPy: Leverages NumPy for numerical computations.

Creation of Dataframes:¶

1.What is Dataframe ? Write it’s key Features and applications.¶

A Pandas DataFrame is a two-dimensional, labeled data structure—similar to a spreadsheet or SQL table—used for organizing, analyzing, and manipulating data in rows and columns. Each column can hold a different data type (integer, float, string, etc.), and both rows and columns have unique labels for easy access.

Key Features¶

  • Two-dimensional, tabular data structure (rows and columns)
  • Columns can have different data types
  • Labeled axes for rows (index) and columns
  • Mutable size; you can add or drop rows and columns
  • Supports arithmetic and statistical operations across axes
  • Flexible data input: create from lists, dicts, arrays, Series, or external files (CSV, Excel, SQL, etc.)
  • Powerful data manipulation: filtering, sorting, merging, grouping, and reshaping
  • Integration with libraries like NumPy and Matplotlib
  • Handles missing data efficiently
  • Easy function application with methods like apply(), map(), and pipe()

Applications¶

  • Data cleaning and preprocessing
  • Exploratory data analysis and summarization
  • Statistical modeling and feature engineering
  • Data transformation, aggregation, and reshaping
  • Reading/writing data from various file formats (CSV, Excel, SQL databases, JSON, etc.)
  • Preparing data for machine learning and visualization tasks
  • Handling time series and time-stamped data
